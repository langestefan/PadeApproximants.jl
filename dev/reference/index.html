PadeApproximants.ReturnCode — Module
ReturnCode

Namespace for the return codes attached to every result, as ReturnCode.T values:

  • ReturnCode.Success: the approximant of the requested type was computed.
  • ReturnCode.DegreeReduced: the approximant is valid, but of lower type than requested, because the coefficients do not support the requested degrees.
  • ReturnCode.Breakdown: the algorithm hit a singular system or a zero divisor. The result holds whatever was computed up to that point and should not be trusted.

See also successful_retcode.

PadeApproximants.ContinuedFraction — Type
ContinuedFraction(prefix, a, m, n, retcode)

Approximant in continued-fraction form,

prefix(z) + zᵏ · a₁ / (1 + a₂z / (1 + a₃z / (1 + …)))

where prefix holds the k coefficients of a polynomial of degree k - 1, constant term first, and a the partial numerators. m and n are the degrees that were requested; the actual degrees are given by degrees. Call the object to evaluate it by backward recurrence: cf(z).

PadeApproximants.PadeProblem — Type
PadeProblem(c; m, n)
PadeProblem(c, m, n)

Problem of finding the Padé approximant of type (m, n) to the power series with coefficients c, stored constant term first (c[1] is c₀). m is the numerator degree and n the denominator degree.

If neither degree is given, all coefficients are used for the (near-)diagonal approximant: n = (length(c) - 1) ÷ 2 and m = length(c) - 1 - n. If only one is given, the other takes the remaining coefficients.

Throws an ArgumentError if c has fewer than m + n + 1 coefficients. Coefficients beyond the first m + n + 1 are ignored.

PadeApproximants.PointEstimate — Type
PointEstimate(value, at, abserr, m, n, retcode)

Value of the type (m, n) approximant at the single point at. abserr is the absolute difference from the previous approximant in the same sequence, which serves as an error estimate. Get the value with value.

source
PadeApproximants.RationalApproximant — Type
RationalApproximant(p, q, m, n, retcode)

Rational function p(z) / q(z), with coefficient vectors p and q stored constant term first and q[1] == 1. m and n are the degrees that were requested; the actual degrees are given by degrees. Call the object to evaluate it: r(z).
